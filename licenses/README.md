# 许可证与源码归档

本目录包含 Motrix Lite 1.1.1 分发所需的全部许可证文本、第三方清单与源码要约。
APK 内 `assets/licenses/` 会同步打包这些文件（README 除外）。

| 文件 | 说明 |
| --- | --- |
| `GPL-3.0.txt` | 本项目整体许可证（GPLv3 全文） |
| `GPL-2.0.txt` | aria2 的 GPLv2 全文 |
| `aria2-COPYING.txt` | aria2 1.35.0 原始 COPYING |
| `aria2-LICENSE.OpenSSL` | aria2 的 OpenSSL 链接例外原文（适用于 OpenSSL 1.1.1d） |
| `aria2-OpenSSL-Exception.txt` | 例外文本与适用性说明 |
| `OpenSSL-1.1.1d-LICENSE.txt` | OpenSSL 1.1.1d 的 OpenSSL + SSLeay 双许可证全文 |
| `zlib-1.2.9-zlib-license.txt` | zlib 1.2.9 |
| `c-ares-1.14.0-MIT.txt` | c-ares 1.14.0（MIT） |
| `libexpat-2.2.9-MIT.txt` | expat 2.2.9（MIT） |
| `libssh2-1.9.0_DEV-BSD-3-Clause.txt` | libssh2 1.9.0_DEV（BSD-3-Clause） |
| `Apache-2.0.txt` | Apache-2.0 全文（Kotlin/AndroidX/libc++ 等） |
| `Gopeed-LICENSE.txt` | Gopeed v1.9.3 GPL-3.0 全文 |
| `devgianlu-aria2-android-LICENSE` | devgianlu/aria2-android 仓库许可状态说明（该仓库无 LICENSE 文件） |
| `DEPENDENCY-VERSIONS.md` | 二进制静态依赖精确版本、submodule pin 与证据 |
| `THIRD_PARTY_NOTICES.md` | 完整第三方组件清单（仓库根目录同名文件为权威版本） |
| `SOURCE-OFFER.txt` | 对应源码获取方式与书面要约 |

对应源码归档不提交 git（体积原因），随 GitHub Release 附件分发：
`aria2-1.35.0-source.tar.gz`、`Gopeed-v1.9.3-source.zip`、
`devgianlu-aria2-android-build-files.zip`、`MotrixLite-1.1.1-licenses.zip`。
